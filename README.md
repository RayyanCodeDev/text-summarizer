# MindNova - AI Text Summarizer

🚀 Turn long text into Twitter threads, bullet points, and action items in 1 click.

## Features
- 🧠 AI-powered summarization using Groq's Llama 3.1
- 📝 Multiple output formats: Concise, Bullet Points, Twitter Thread, Simple English, Action Items
- 📥 Download summaries as .txt files
- 🕐 Local summary history (saves last 3 summaries with a clear button)
- 🔒 100% free, no login required

## Tech Stack
- Backend: Python, Flask, Groq API
- Frontend: HTML, CSS, JavaScript
